# 🎯 GTA 6 Heist Planner — ViceBot AI

## ⚡ Deploy in 5 minuten via Vercel

### Stap 1 — Lokaal opzetten
```bash
npm install
npm run dev
```
Open http://localhost:5173

### Stap 2 — Naar GitHub
```bash
git init
git add .
git commit -m "GTA6 Heist Planner launch"
git remote add origin https://github.com/JOUWUSERNAME/gta6-heist-planner.git
git push -u origin main
```

### Stap 3 — Deploy op Vercel (gratis)
1. Ga naar vercel.com → Log in met GitHub
2. Klik "Add New Project"
3. Kies je gta6-heist-planner repo
4. Framework: **Vite** — alles automatisch
5. Klik "Deploy" → klaar!

### Stap 4 — Eigen domein koppelen
In Vercel dashboard → Settings → Domains
Voeg toe: `gta6heist.com` of `vicebot.gg`
DNS instelling: CNAME → cname.vercel-dns.com
